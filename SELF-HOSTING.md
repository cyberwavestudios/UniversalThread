# Universal Thread — designer handoff

This directory is a screened static release of the Universal Thread app. Serve its contents from the root of an HTTPS website. It contains `index.html`, `threaded-ladder.html`, and `cosmic-harmony.html`; no build, package installation, database, or Replit service is required for these pages. The original Replit archive and secrets are preserved separately and are **not** included here.

Local check on October 4, 2026: all three pages loaded independently from Replit at `127.0.0.1:8771`, and the browser reported no script errors during page navigation. The main clock rendered, The Threaded Ladder opened, and Cosmic Harmony displayed its controls. This is not yet a test of the designer's server, mobile layout, or audible harmonic output.

The current public domain is `universal-time.cyberwavestudios.com`. Leave its DNS pointing to Replit until the new HTTPS site has been checked by the owner. The original Replit app was not changed.
